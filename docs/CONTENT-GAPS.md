# Content gaps before publication

The site works without these details. Missing facts are omitted rather than replaced with fictional chronology or conspicuous filler.

1. **Education:** exact awarded qualification, institution, graduation date and optional classification. Computer Science degree is shown because the user confirms it; none of the missing specifics is guessed.
2. **Professional experience:** verified employers, titles, dates, responsibilities and public-safe examples. Current section presents project practice / education / direction, not a fabricated employment timeline.
3. **Current resume:** provide an approved PDF for `public/` or confirm a maintained public link. Until then the CTA is “Request my resume” via email, not a broken download.
4. **Infrastructure case studies:** sanitized architecture diagrams/config, personal contribution, constraints and evidence for AKS/Helm, Azure Key Vault/private DNS, GCP networking/voice, self-hosted runners or Azure AI agents. Do not disclose live endpoints, tenant identifiers or secrets.
5. **Kamus26:** actual repository/branch/commit and contribution summary. Only an upstream Kamus fork is publicly visible; original authors must remain credited.
6. **Team AI project:** specific contribution to NBA salary prediction, implemented model/source, and permission to use team artifacts.
7. **LinkedIn:** manually verify the profile link; automated requests return 999.
8. **Canonical origin:** set `SITE_URL` to the actual approved hosting origin before building for publication. Local builds intentionally use localhost. No custom domain has been invented.

Priority: current resume and professional chronology, then one evidence-rich infrastructure case study. Real depth matters more than adding cards. No certifications or training programs should be added without confirmation.
